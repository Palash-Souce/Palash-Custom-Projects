Project Title: Java Desktop Camera Automation Utility
The Problem It Solves: Automates photo capture via the built-in system webcam using native Java execution combined with light automation scripting. (Perfect for kiosks, internal verification systems, or security logging).
The Stack Used: Core Java, Windows Batch Scripting, Local Executables
How It Works: The .bat file handles execution, the .java orchestrates the logic, and it outputs a clean my_selfie.png file.
